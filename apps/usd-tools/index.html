USD tools

OpenUSD's command-line tools, run in this page by TypeScript USD. Choose a sample or open your own files; nothing leaves the device.

  • 🐈usdcat

    Drop a file and the cat converts it: .usda to .usdc, .usdc to .usda. Flattening is in its settings.

  • ✏️usdzip

    Drop a USD file or its folder: everything it uses goes into a pencil case that zips up into a .usdz.

  • 🕵️usdchecker

    Hand a file to the inspector: he looks it over and stamps a report, every finding grouped by the rule it breaks.

  • 🦉usddiff

    Put two files on either side of the owl: it compares them as USD sees them and lays the changes out side by side.

  • 🕊️usdresolve

    A homing pigeon carries each asset path a layer names to the file it resolves to, in a little town of your files.

  • 🐭usdstitch

    A tailor mouse sews your USD files into one quilt, the first the strongest, time samples merged.

  • 🎞️usdstitchclips

    The same mouse sews clip files into a film strip: value clips on one prim, with their topology and manifest.

  • 🤖usdfixbrokenpixarschemas

    A fix-it robot mends the schema mistakes older files make with Pixar’s schemas and shows you what it changed.

Samples: four exhibits from the USD Museum (CC0 1.0), the witches' heath from TypeScript USD's Stagehand example, a bouncing ball in four clips made for these pages, and the inputs of OpenUSD's own tests for usdfixbrokenpixarschemas. Pixar's Kitchen Set is not included, since its licence does not allow passing it on; open your own copy with Open folder.
