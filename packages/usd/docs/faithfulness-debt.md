edit by hand. It is regenerated from the `FAITHFULNESS-DEBT` and `PLATFORM-DIVERGENCE` comments.

- **`FAITHFULNESS-DEBT(<id>)`** marks a stand-in for an upstream mechanism that can be ported: the
  comment names the upstream code (file:line) and the faithful replacement. Retiring an id means
  porting that mechanism and deleting every marker of the id.
- **`PLATFORM-DIVERGENCE(<id>)`** marks a difference that JavaScript, the browser or WebGPU forces
  (no pointer identity or `use_count`, no shared-memory threads, asynchronous GPU readback, no OpenGL,
  WebGPU feature limits). It is documented, not retired, unless the platform changes.

User-visible effects and their evidence are in [KNOWN-GAPS.md](../../../KNOWN-GAPS.md).
