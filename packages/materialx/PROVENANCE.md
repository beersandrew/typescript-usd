# Provenance

Upstream: MaterialX 1.39.5
(https://github.com/AcademySoftwareFoundation/MaterialX, tag `v1.39.5`,
`7b64921ef1d42f2d57871e9d2c43dc11f041f26b`), Copyright Contributors to the
MaterialX Project, Apache License 2.0. This is the MaterialX the OpenUSD 26.11.1
reference build links. The generator code follows v1.39.5 plus ten later
upstream commits, which change no generator code under GenShader, GenHw or
GenGlsl except `MaterialXGenShader/Util.cpp`. `core/src/util.ts` reports
version 1.39.6 (`MATERIALX_BUILD_VERSION` 6), where v1.39.5's
`CMakeLists.txt` sets 5; the exact upstream commit the core port followed was
not recorded.

| Here | Upstream | Package |
|---|---|---|
| `core/` | `source/MaterialXCore/` | `@mtlx/core` |
| `format/` | `source/MaterialXFormat/` | `@mtlx/format` |
| `genshader/` | `source/MaterialXGenShader/` | `@mtlx/genshader` |
| `genhw/` | `source/MaterialXGenHw/` | `@mtlx/genhw` |
| `genglsl/` | `source/MaterialXGenGlsl/` | `@mtlx/genglsl` |
| `render/` | `source/MaterialXRender/{LightHandler,Image}` | `@mtlx/render` |
| `libraries/` | `libraries/` (data, verbatim) | `@mtlx/libraries` |

Each ported source file starts with a header naming the upstream files it
ports. Files without one (`format/src/virtualFs.ts`, the `index.ts` barrels)
have no upstream counterpart. `format/src/xml.ts` reimplements the parts of
PugiXML (embedded in MaterialXFormat, MIT License, Copyright (c) 2006-2018
Arseny Kapoulkine) whose behaviour `.mtlx` round trips depend on.

Points where this port follows upstream rather than an obvious TypeScript
shape, each marked at its site:

- `genglsl/src/vkShaderGenerator.ts`, `vkSyntax.ts`,
  `vkResourceBindingContext.ts`: ported file per file from
  `source/MaterialXGenGlsl/Vk*.{h,cpp}`; Storm uses them for Vulkan-style Hgi
  back ends.
- `genshader/src/shaderStage.ts` `addBlock`: a trailing newline does not
  produce an extra empty line, as `std::getline` (ShaderStage.cpp:320-342).
- `genhw/src/nodes/hwGeomPropValueNode.ts` and
  `genglsl/src/glslShaderGenerator.ts`: the geompropvalue vertex-data
  connector is named `T_IN_GEOMPROP + "_" + name`, as upstream
  (HwGeomPropValueNode.cpp:34-35, GlslShaderGenerator.cpp:645).
- `genshader/src/genContext.ts`: `copy()` stands in for the C++ implicit copy
  constructor (`GenContext copy = context;`).

Packaging: each package's `exports` point at `src/*.ts` so workspace
consumers compile the sources directly (the `dist/` exports are under
`publishConfig`).

## Data libraries

`libraries/src/generated/files.ts` is generated by
`libraries/scripts/generate.mjs` from a MaterialX checkout at tag v1.39.5
(the script checks the commit): every `.mtlx` under upstream `libraries/` and
the `genglsl` shader sources, with their paths relative to `libraries/`.
These are the libraries the reference build installs
(`<install>/lib/usd/usdMtlx/resources/libraries`, identical to v1.39.5
`libraries/` for these files). `libraries/src/index.ts` mounts them in
`@mtlx/format`'s virtual file system. `stdlib/genglsl/lib/mx_noise.glsl` and
`mx_hsv.glsl` are derived by MaterialX from Open Shading Language (BSD
3-Clause License); their notices are kept verbatim in the embedded text and
reproduced in [NOTICE](NOTICE).
